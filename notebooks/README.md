# Notebooks

This directory is reserved for exploratory Jupyter notebooks.

## Guidelines

- Notebooks are for **exploration and prototyping only**
- Any analysis that produces findings should be formalized in `src/analysis/`
- Notebooks should not be required to run the dashboard or generate reports
- Name notebooks descriptively: `01_explore_event_distribution.ipynb`

## Suggested Explorations

- Profile GA4 event parameter keys and value distributions
- Explore item category hierarchies
- Test SQL queries before adding to dbt models
- Prototype visualizations before adding to the dashboard
